❤️ About BloodLink

Connecting Blood.
Connecting Hope.

BloodLink is a blood donor management system designed to make donor registration, donor searching, blood requests and blood group information simple and accessible.

🩸
Our Project

What is BloodLink?

BloodLink is a college project created to demonstrate how technology can be used to organize blood donor information and make blood-related services easier to access.

The system brings together donor registration, donor search, blood requests and blood compatibility information in one platform.

Our goal is to create a simple and user-friendly experience where important blood information can be managed efficiently.

Our Purpose

Built Around a Simple Mission

BloodLink focuses on making blood donor management organized, accessible and easy to understand.

🩸

Our Mission

To provide a simple digital platform that helps organize blood donor information and supports faster access to relevant donor and blood request information.

❤️

Our Vision

To demonstrate how a connected blood management system can bring donors, requests and useful blood information together in a single platform.

How BloodLink Works

A Simple Four-Step Flow

The system is designed around a straightforward journey for users.

1

Create Account

Users create a BloodLink account using their basic information.

2

Register as Donor

Eligible users can provide their blood group, location and contact information.

3

Find or Request

Users can search donors or submit a blood request through the system.

4

Connect

Relevant donor and request information can be viewed through the BloodLink platform.

BloodLink Features

Everything in One Place

The project combines several useful blood management functions into a single web application.

🩸

Donor Registration

Registered users can provide their blood group, location and mobile number to become donors.

🔎

Donor Search

Search for registered donors based on blood group and city or district.

🚨

Blood Requests

Users can submit blood requests with relevant patient and contact information.

🧬

Compatibility

The system provides a blood group compatibility checker for educational purposes.

🔐

Account System

Users can create accounts and log in before accessing donor registration features.

💾

JSON Storage

The backend demonstrates data management using JSON files without requiring a SQL database.

Technology

How BloodLink Is Built

BloodLink uses a simple web architecture suitable for demonstrating a complete frontend and backend blood management system.

Frontend: HTML, CSS and JavaScript
Backend: Node.js and Express
Storage: JSON files
Communication: REST API
Important: BloodLink is a college project and is intended to demonstrate blood donor management concepts. It should not replace hospitals, blood banks, laboratory testing, medical professionals or official emergency services.
